# progressgoat

Daily logging — one line per day. Press **Enter** to save.

- **Day switcher** — ← → at the bottom (click the date to jump to today)
- **Streak** — consecutive days with an entry (top right)
- **Export** — copies the last 30 days as Markdown

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
